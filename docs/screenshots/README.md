# Screenshots

Used in the README and in the CWP forum thread.

**Every account identifier in these is fictional.** They were taken from a live server and
the identifying text was replaced - not blurred and not boxed over. The original glyphs are
overwritten with the sampled page background before the substitutes are drawn, so there is
nothing left to recover, and the files carry no metadata beyond the image itself.

Addresses are RFC 5737 documentation IPs (`203.0.113.0/24`), which are reserved and cannot
belong to anyone.

| File | Shows |
|---|---|
| `client-area-dashboard.png` | Account dashboard: allowances, and the domain, subdomain and database panels |
| `client-area-mailboxes.png` | Mailbox management: the list, and the create form |

Not shipped in the release archive - `tools/build-release.php` excludes `docs`.
